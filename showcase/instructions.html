03 / TELEGRAM

Открыть CONNECT.md ↗

Реальный бот не зарегистрирован. Доставка сообщений в Telegram не проверялась.

От кода до локального диалога

  1. Скачайте ZIP по ссылке выше и распакуйте его.
  2. Откройте терминал в распакованной папке repairdesk-telegram-demo-main, где находятся README.md и папка repairbot/.
  3. Выполните команду запуска:
python3 -m repairbot demo

Затем откройте http://127.0.0.1:8783/. Этот адрес работает только после запуска сервера на вашем компьютере.

На Windows: py -3 -m repairbot demo. Остановка: Ctrl+C. Учебные данные сохраняются в SQLite. Переключатель ролей существует только для локального показа.

Контакт остаётся добровольным

В локальном стенде контакт синтетический. В настоящем ядре после явного согласия переданный телефон временно хранится в черновике. Команда /cancel удаляет черновик; подтверждение создаёт заявку с телефоном. Можно продолжить без телефона. После создания контакт отзывается командой /withdrawcontact НОМЕР.

Эта публичная страница контакты не запрашивает и не хранит, заявки не создаёт. GitHub Pages показывает статическую витрину; Python-бот здесь не работает.
