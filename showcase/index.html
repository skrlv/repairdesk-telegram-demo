КОД, КОТОРЫЙ МОЖНО ПРОВЕРИТЬ

Демонстрация с продолжением.

01 / ПРИЁМ

Обращение по шагам

Устройство, описание, фото, контакт по желанию и подтверждение. Незавершённый черновик можно отменить.

02 / ДОСТУП

Своя заявка — своему клиенту

Права проверяет ядро бота. Сотрудники задаются списком Telegram ID в переменных окружения.

03 / ХРАНЕНИЕ

Заявка и её история

SQLite хранит черновики, заявки и изменения статусов. В реальном режиме сохраняется Telegram file_id фотографии.

ДЛЯ РЕАЛЬНОГО ПОДКЛЮЧЕНИЯ

Токен, ID сотрудников и среда запуска.

В комплекте есть отдельный транспорт Telegram Bot API. Для работы в Telegram владелец подключает свой токен и запускает процесс бота. GitHub Pages показывает только эту витрину; сервер бота здесь не работает.
